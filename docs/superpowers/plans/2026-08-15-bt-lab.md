### Task 6: FastAPI 服务 server.py

**Files:**
- Create: `webapp/server.py`
- Create: `webapp/webapp/__init__.py` 不需要（python -m webapp.server 时 Package 需要 `webapp/__init__.py`）→ Create: `webapp/__init__.py`（空）

API（全部 JSON；路径见规格 3 节）：
- `GET /` → FileResponse static/index.html
- `GET /api/datas` → `{builtin:[{name,path,rows,dtformat,date_first,date_last}],uploads:[…]}`（缓存 inspect 结果，uploads 变化时失效）
- `POST /api/datas/inspect` `{path}` → inspect_csv 结果
- `POST /api/datas/upload` multipart `file` → 存 `webapp/uploads/<安全文件名>` → inspect 结果
- `GET /api/strategy/templates` → TEMPLATES
- `POST /api/run` → TaskManager.submit(request) → `{task_id, queued: bool}`
- `GET /api/task/{id}` → `{id,status:queued|running|done|error|killed, started, finished, error, result?, chart_svg?, progress:{done,total}}`
- `POST /api/task/{id}/kill`
- `GET /api/tasks` → 最近 10 个任务摘要

TaskManager（threading）：
```python
class TaskManager:
    queue: deque[str]  # task dirs
    current: str | None
    proc: subprocess.Popen | None
    worker 线程: 取队首 → Popen([sys.executable, 'webapp/runner.py', task_dir], cwd=REPO_ROOT)
               → proc.wait()（30 分钟超时 kill）→ 处理下一个
    kill(id): proc.terminate/kill，status 写 killed
```
- task_id = `YYYYmmdd-HHMMSS-xxxx`；`webapp/tasks/<id>/request.json|status|error.txt|result.json|chart.svg|progress.jsonl`
- status 文件内容即状态机：`queued`（入队即写）/`running`/`done`/`error`/`killed`
- 启动：`uvicorn webapp.server:app --port 8600`（README 提供一条 `.venv/bin/python -m uvicorn webapp.server:app --port 8600 --app-dir .`）
